# Smart Delivery Planning – Fractional Knapsack

Analysis of Algorithm (AOA) PBLE Project

## Description

A menu-driven C program that solves the Fractional Knapsack problem using the Greedy Algorithm. The program calculates the Value/Weight ratio of each package, sorts the packages based on the ratio, and finds the maximum value that can be carried within the given vehicle capacity.

## Features

- Enter package details
- Display package details
- Calculate Value/Weight ratio
- Sort packages by Value/Weight ratio
- Find maximum achievable value
- Display selected packages and quantities
- Supports fractional selection of packages

## Algorithm

Fractional Knapsack using Greedy Method.

## Technology Used

- Language: C
- Concepts: Greedy Method, Fractional Knapsack, Sorting
